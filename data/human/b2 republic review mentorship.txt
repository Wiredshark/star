Keene starts rewriting the file as a sequence of questions instead of a sequence of facts. Noll says, "Good. A precedent should teach what had to be justified, not who happened to be standing at the desk."`

Keene looks relieved. "So the training object is the explanation, not the old case." Noll nods. "And a supervisor can hear when an inference has quietly turned into a fact."`
			action

				"B2 Republic Review Mentorship: route supervised clinic" = 1
				"B2 Republic Review Mentorship: noll trusts player" = 1

			action

				"B2 Republic Review Mentorship: route private mentorship" = 1

mission "B2 Republic Review Mentorship: Practice Review"
	minor
	name `The Observer's Question`
	description `Mara Keene returns after testing the training rule against ordinary Republic review work.`
	source
		government "Republic"
		not attributes "station"
	"offer precedence" 8
	to offer
		has "B2 Republic Review Mentorship: introduced"
		has "B2 Republic Review Mentorship: practice ready"
		not "B2 Republic Review Mentorship: reviewed"
	on offer
		conversation
			branch casebook
				has "B2 Republic Review Mentorship: route anonymized casebook"
			branch clinic
				has "B2 Republic Review Mentorship: route supervised clinic"
			`Keene finds you with Noll nearby. "The private mentorship worked, but it has a weakness. Two observers can learn the same principle from Sera and still write completely different records. We need some durable structure without turning your review into the template."`
				goto settle
			label casebook
			`Keene shows you an anonymized training file. "The casebook preserved the sequence, but one trainee treated the example as a checklist and skipped the part where the factual basis was supposed to change the next step. The file needs explicit stop points: places where an observer has to say why the review may continue." Noll says the same mistake is how administrative habits become invisible authority.`
				goto settle
			label clinic
			`Keene says the live clinics exposed weak reasoning quickly, but supervisors disagreed about what counted as an adequate explanation. "One heard 'route pattern' and accepted it. Another demanded the examiner identify what was unusual about the pattern. We need a common review record, not a common conclusion."`
			label settle
			choice
				`\tAdopt an abstract safeguards record: every review logs evidence, inference, scope authority, consent boundary, and the reason for each escalation.`
					goto safeguards
				`\tAdopt supervised review circles: observers compare live cases using a shared reasoning rubric, but no prior captain's file becomes binding precedent.`
					goto circle
			label safeguards
			`You recommend a short safeguards record attached to every elevated review. It does not dictate the answer; it forces each office to separate evidence from inference, identify its authority, record consent limits, and explain every escalation. Keene says that gives trainees something durable to compare without borrowing the identity of an older case. Noll calls it "portable accountability instead of portable suspicion."`
			action
				"B2 Republic Review Mentorship: reviewed" = 1
				"B2 Republic Review Mentorship: settlement safeguards record" = 1
				"B2 Republic Review Mentorship: noll trusts player" = 1
				"B2 Republic Review Mentorship: keene trusts player" = 1
				accept
			label circle
			`You recommend supervised review circles. Trainees bring current cases, state the evidence/inference boundary aloud, and compare reasoning against a shared rubric. Prior files may supply questions, never binding answers. Keene says it keeps the training social enough to expose weak assumptions. Noll says it also keeps responsibility with the current observer instead of letting a dead file make the decision.`
			action
				"B2 Republic Review Mentorship: reviewed" = 1
				"B2 Republic Review Mentorship: settlement supervised review circle" = 1
				"B2 Republic Review Mentorship: keene trusts player" = 1
				accept
